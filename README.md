# Goals Championship Service

The Goals Championship Service is a user interface application designed to fetch and aggregate goal-tracking data from multiple sources, such as Zenkit, Todoist, and Notion. Its primary purpose is to provide users with a unified view of their project and goal management data, enabling them to process this information and determine their overall level of productivity

## Key Features

- **Multi-source Integration:** Fetches data from external services like Zenkit, Todoist, and Notion, aggregating information for projects, lists, and goals in one place.
- **Modern UI Architecture:** Implements a blueprint-based controller structure for scalability and ease of maintenance.
- **Project and Goal Management:** Provides intuitive UI components for listing and viewing projects and goals, with support for multiple organizational structures.
- **User Experience Features:** Includes tools like a project selector, copy buttons, and alert notifications to improve usability and feedback.
- **Robust Data Handling:** Offers flexible handling of column names, date formats, and data normalization to ensure consistent presentation and reliability.
- **Environment and Deployment Ready:** Comes with example environment configuration files and a Dockerfile for straightforward deployment.
